# TritonAI Audience Contracts

This file defines the editorial contract and canonical sequence for each supported audience. The `all` view remains the complete editorial library and is not a recommended presentation.

## Routing principles

- Each audience has one opening, a cumulative narrative, and one purposeful closing.
- Slides are included because they advance the audience’s communication job, not because they are broadly interesting.
- Sensitive performance material is internal-only.
- Stable slugs remain the routing contract for direct links.
- Counts are validated from the canonical sequences below.
